# NexRes

Cambiador de resolución y densidad para Android usando Shizuku o root.

## Qué hace
- Ajusta resolución (`wm size`) y densidad (`wm density`)
- Perfiles rápidos para aplicar combinaciones guardadas
- 2 pantallas compactas: Pantalla y Ajustes
- Ajustes: estilo Material/MIUIX, colores de acento, fuente global, idioma, info de app

## Requisitos
- Android 8.0+
- Shizuku activo con permiso concedido, o acceso root

## Build
El APK release se compila y firma en GitHub Actions (`.github/workflows/build.yml`).
